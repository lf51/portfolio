Kebijakan Privasi

Pembaruan terakhir: 03.02.2026
Terima kasih telah menggunakan Unison. Privasi Anda sangat penting bagi kami. Kebijakan Privasi ini menjelaskan bagaimana aplikasi menangani informasi. Unison tidak mengumpulkan, menyimpan, atau membagikan data pribadi kepada pengembang maupun pihak ketiga. Semua data diproses secara lokal di perangkat Anda dan di dalam jaringan lokal Anda.

1. Komunikasi Jaringan Lokal

Unison menghubungkan perangkat di sekitar menggunakan framework Multipeer Connectivity dari Apple. Komunikasi ini hanya terjadi di dalam jaringan lokal dan digunakan untuk mengoordinasikan perekaman serta transfer video antar perangkat.

Tidak ada data yang dikirim ke server eksternal dan koneksi internet tidak diperlukan untuk fungsi ini.

2. Data yang Disimpan Secara Lokal

Unison menyimpan sejumlah kecil data secara lokal di perangkat Anda menggunakan UserDefaults:

  • Daftar perangkat tepercaya: daftar perangkat yang sebelumnya telah diotorisasi oleh pengguna untuk menghindari permintaan izin berulang.

Daftar ini dapat diatur ulang kapan saja melalui pengaturan aplikasi. Tidak ada informasi pribadi atau identitas yang dikaitkan dengan perangkat ini.

3. Pengelolaan Media

Bergantung pada peran yang ditetapkan (Master atau Node), Unison dapat merekam video dan mentransfer file media antar perangkat.

  • Video disimpan secara lokal di perangkat penerima;
  • Konten media tidak diunggah, dianalisis, atau dibagikan ke pihak luar;
  • Semua transfer dilakukan langsung antar perangkat di jaringan lokal.

4. Izin Akses

Unison dapat meminta akses ke kamera, mikrofon, jaringan lokal, dan pustaka media untuk menyediakan fungsi utama aplikasi.

Unison tidak mengakses atau mengumpulkan data di luar yang benar-benar diperlukan untuk menjalankan aplikasi.

5. Autentikasi dan Akun

Unison tidak menggunakan sistem autentikasi, akun pengguna, atau layanan identitas. Tidak diperlukan login untuk menggunakan aplikasi.

6. Pembayaran dan Langganan

Unison sepenuhnya gratis untuk digunakan. Tidak ada langganan, pembelian dalam aplikasi, atau sistem pembayaran apa pun.

7. Pihak Ketiga

Unison tidak mengintegrasikan SDK iklan, alat analitik, sistem pelacakan, atau layanan pihak ketiga lainnya.

8. Penyimpanan dan Penghapusan Data

Semua data yang ditangani oleh Unison (video dan daftar perangkat tepercaya) tetap berada di perangkat Anda. Menghapus aplikasi akan menghapus seluruh data yang tersimpan secara lokal secara permanen.

9. Privasi Anak

Aplikasi ini ditujukan untuk pengguna umum dan tidak secara sadar mengumpulkan data pribadi dari anak-anak.

10. Perubahan pada Kebijakan Privasi Ini

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu. Setiap perubahan akan ditampilkan dalam dokumen ini dengan tanggal “Pembaruan terakhir” yang diperbarui.

11. Kontak

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini, silakan hubungi tim pengembang.

Dengan menggunakan Unison, Anda menyetujui ketentuan yang dijelaskan dalam Kebijakan Privasi ini.
